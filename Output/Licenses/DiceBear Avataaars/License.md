# Avatars: DiceBear "Avataaars" style

40 of the profile avatars under `Profiles/Vocaluxe Avatars 2024 (Official)/`
(added 2026-09-18) are generated illustrations in the "Avataaars" style,
served through the [DiceBear](https://www.dicebear.com/) HTTP avatar API
(`https://api.dicebear.com/10.x/avataaars/png`), one per profile name used as
the `seed`.

Original design: [Avataaars](https://avataaars.com/) by Pablo Stanley
([@pablostanley](https://twitter.com/pablostanley)), "free for personal and
commercial use". The DiceBear adaptation is licensed **CC BY 4.0**.

No real people are depicted, so unlike photographic avatars this style
carries no personality-rights concerns for redistribution.
